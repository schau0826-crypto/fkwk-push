# AI 助手与通知记忆

fkwk-push 可以把 Android 捕获到的通知作为结构化事件上报到可选的 AI Hub。AI Hub 负责长期记忆、每日/实时简报、Todo 草稿和确认后的 Bark 提醒。

## 架构

```text
Android app
  通知监听 / 本地历史 / Bark 转发
        |
        | POST /ai/events
        v
AI Hub on server
  SQLite memory / OpenAI-compatible analysis / Todo drafts
        |
        | Feishu webhook digest + action links
        v
Feishu Agent / bot
        |
        | confirm action
        v
Bark reminder to iPhone
```

Android 端仍然是轻量采集器，不运行 agent runtime。OpenClaw/Hermes 可以通过标准 HTTP API 接入 AI Hub。

## Android 配置

在设置页打开 `AI Hub`：

```text
启用 AI 事件上报：开
AI Hub 地址：https://your-domain.example:8443
AI Hub Token：server/.env 里的 AI_HUB_TOKEN
```

打开后，以下通知状态都会上报：

- Bark 已转发
- Bark 发送失败
- 关键词屏蔽
- 亮屏且未锁屏时跳过

## 服务端配置

复制配置：

```bash
cd server
cp .env.example .env
```

关键变量：

```text
AI_HUB_TOKEN=change-me-ai-hub-token
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_API_KEY=your-openai-compatible-key
OPENAI_MODEL=gpt-4o-mini
FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/xxx
BARK_SERVER_URL=https://api.day.app
BARK_DEVICE_KEY=your-bark-key
```

`OPENAI_BASE_URL` 使用 OpenAI-compatible 协议，可替换为 OpenAI、OpenRouter 或自建兼容接口。

## API

### Health check

```bash
curl https://your-domain.example:8443/healthz
```

### Ingest notification event

```bash
curl -X POST https://your-domain.example:8443/ai/events \
  -H "Authorization: Bearer $AI_HUB_TOKEN" \
  -H "Content-Type: application/json" \
  --data @server/ai-hub/sample-event.json
```

### Generate daily digest

```bash
curl -X POST "https://your-domain.example:8443/ai/digests/daily?hours=24&send=1" \
  -H "Authorization: Bearer $AI_HUB_TOKEN"
```

`send=1` 会把简报发送到飞书 webhook。没有配置 `FEISHU_WEBHOOK_URL` 时，只返回 JSON。

### Confirm action

AI Hub 会给 Todo 生成 action id。确认后会通过 Bark 推送提醒：

```bash
curl -X POST "https://your-domain.example:8443/ai/actions/<action_id>/confirm?token=$AI_HUB_TOKEN"
```

也支持：

```text
ignore
snooze
```

### Delete memory

按 App 删除：

```bash
curl -X DELETE "https://your-domain.example:8443/ai/memory?package=com.tencent.mm" \
  -H "Authorization: Bearer $AI_HUB_TOKEN"
```

按关键词删除：

```bash
curl -X DELETE "https://your-domain.example:8443/ai/memory?keyword=验证码" \
  -H "Authorization: Bearer $AI_HUB_TOKEN"
```

按时间删除，`before` 为毫秒时间戳：

```bash
curl -X DELETE "https://your-domain.example:8443/ai/memory?before=1760000000000" \
  -H "Authorization: Bearer $AI_HUB_TOKEN"
```

## MVP 边界

- 飞书第一版使用 webhook 文本消息和确认链接，不直接绑定某个 agent 框架。
- OpenClaw/Hermes 后续可通过 `/ai/events`、`/ai/digests/daily`、`/ai/actions/*` 接入。
- 所有外部动作默认需要确认；AI 只生成 Todo 草稿。
- 如果没有配置 OpenAI-compatible API，AI Hub 会退化为本地启发式摘要。
