# 可选服务端

正常使用 fkwk-push 不需要部署服务端。Android app 可以直接调用 Bark 官方服务：

```text
https://api.day.app
```

`server/` 目录只用于可选能力：

- 自托管应用图标，让 Bark 通知显示来源 App 图标
- 保留旧版 ntfy Docker 配置，作为参考或备用实验

## Icon Upload Service

Bark 支持在推送请求里传入 `icon` URL。fkwk-push 可以在 Android 端读取应用图标，并上传到你自己的服务器：

```text
https://your-domain.example/icons/<package>.png
```

然后 Bark 推送会带上这个 URL。

## Configuration

复制示例配置：

```bash
cd server
cp .env.example .env
```

填写：

```text
NTFY_DOMAIN=push.example.com
PUBLIC_HTTPS_PORT=8443
ACME_EMAIL=you@example.com
DNS_PROVIDER=cloudflare
DNS_API_TOKEN=your-dns-api-token
ICON_UPLOAD_TOKEN=change-me-icon-upload-token
```

如果只需要图标上传，仍可以复用当前 Docker Compose。后续也可以把 icon-uploader 单独拆出来部署。

## Deploy

```bash
cd server
./deploy.sh
```

## Security

不要提交真实 `.env`，尤其是：

- DNS API token
- icon upload token
- ntfy admin password

仓库根目录 `.gitignore` 已忽略 `.env` 和常见密钥文件。
