# Android 保活配置

代码层已经提供：

- 通知监听服务
- 前台服务
- 开机自启入口
- WorkManager 重试
- 可选无障碍服务作为保活辅助

但不同 Android 厂商会有自己的后台限制，稳定转发通常还需要手动配置。

## 必做

1. 授予通知读取权限
   - App 内点击“通知读取”
   - 在系统页面打开 fkwk-push 的通知读取权限

2. 允许通知
   - 前台服务需要显示常驻通知
   - 如果系统禁止本 App 通知，后台稳定性会下降

3. 允许自启动
   - 在系统应用管理里找到 fkwk-push
   - 打开自启动或开机启动

4. 电池策略设置为无限制
   - 不要选择智能限制、省电限制、深度休眠等模式

5. 允许后台联网
   - 确保 Wi-Fi 和移动网络后台联网都允许

6. 锁定后台任务
   - 在最近任务页面锁定 fkwk-push，减少被一键清理杀掉的概率

## 可选

开启无障碍保活服务：

- App 内点击“无障碍保活”
- 找到 fkwk-push 对应服务并开启

这个服务不读取屏幕内容，不执行点击，只作为部分系统上的后台存活辅助。

## Verification

- 让被监听 App 收到一条真实系统通知
- 打开 fkwk-push 的通知历史
- 如果历史有记录但 iPhone 没响，检查 Bark 配置和 iOS 通知权限
- 如果历史没有记录，检查 Android 通知读取权限和来源 App 是否真的弹出系统通知
